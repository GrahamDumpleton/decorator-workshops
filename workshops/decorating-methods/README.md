# Decorating methods

Put a decorator on a method and meet the most common surprise in Python
decorators. See which kinds keep working and which fail, read the error
that names the wrong argument and find out why, locate the instance
sitting in `args[0]`, write a decorator that uses it, and learn which
way round to stack with `@staticmethod` and `@classmethod`.

Fifteen minutes, in a notebook. Python and its standard library only,
nothing to install.
